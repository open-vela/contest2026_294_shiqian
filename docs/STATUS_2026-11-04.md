## 二、喇叭链路（已完成）

**硬件**：STM32N647 SAI1 → ES8388（I2C4，地址 0x10）→ MD8002A → 扬声器。

**已实现**
- SAI1 内核时钟选 IC7（`RCC_CCIPR7.SAI1SEL = 010`），PLL2 生成 11.29 MHz MCLK / 44.117 kHz 帧率
- GPDMA1 通道 → SAI1（请求号 91），通道安全属性齐全（`GPDMA_PRIVCFGR/SECCFGR` + `CTR1.SSEC/DSEC`）
- ES8388 必须在 SAI 启动**之前**配置（顺序依赖，实测）
- 播放路径：tone（内存生成，方波）与 WAV（SD 卡流式，8×16 KB 槽位环 + 独立读卡线程）

**板上实测指标**
```
audio-tone: 400 Hz for 800 ms requested, 830 ms measured (35200 of 35200 frames)
sai: 138 blocks, 4~6 of them started with an empty fifo
```
- 播放时长误差 < 5%
- 无 HardFault、无卡死
- 音量寄存器 `0x30/0x31 = 0x21`（最大），输出使能 `0x04 = 0x3C`

**已发现但暂不阻塞的问题（提一句）**
ES8388 在"上电以来第一次看到 MCLK"之后，I2C 控制口会停止应答，且该状态只能靠**断掉 codec 供电**清除（同一 I2C4 上 AP3216C/EEPROM 始终正常，故 MCU 侧 I2C、引脚、时钟均无问题；实测 `SAI 未启动 → 应答`、`SAI 启动 → -6`、延时 100 ms 仍 `-6`）。因此**按 MCU 复位后无法重新配置 codec，表现为静音**，断电后才恢复。
治本方案需硬件配合：给 ES8388 的 `CE`(pin26) 或 DVDD/PVDD 加一路可控 GPIO/负载开关，由驱动在配置前复位 codec。软件侧已无可解手段。

## 三、以太网 ETH1（单向跑通，端到端未完成）

**硬件**：STM32N647 ETH1（Synopsys GMAC5）+ RMII + YT8512C（PHY 地址 0），RJ45 直连 PC。

**已完成并实测**
| 环节 | 结果 |
|---|---|
| RCC/RIF 配置（AHB5 门控、ETH1 复位、RIF 主设备 6、RIMC 属性） | 通过 |
| PHY 复位与链路协商 | `bmsr=796d`，100 Mbps 全双工 |
| MAC 寄存器（MACVR `0x2052`、HWF0R~3R） | 与实际芯片一致 |
| **接收（RX）** | 帧可收到并交付协议栈：`rx=11`，描述符回写长度正确（`des3=0x30010040` → FL=64 B），`crcerr=0`、`alignerr=0` |
| **发送（TX）** | 帧可发出：`tx=3`、MMC `txgood=3`；ARP 应答按 60 字节最小帧补齐 |
| 环结构与对齐 | 描述符 16 字节步长、32 字节对齐，启动时回读 `DMACxDLAR` 校验 |

**未完成**
端到端 `ping` 尚未打通。已排除：RISAF/RIF 拦截（`IASR=0`）、总线错误（`DMACSR.FBE=0`）、环地址被截断（已修并对齐）、`RXPBL=0` 非法值（已按 RM0486 改为 32 拍）、`DMACRXDTPR` 语义（已按 RM0486 改为"环尾之后"）。
剩余疑点集中在**接收环的推进/回收**：日志中出现过"两个已完成的描述符（`OWN` 已清、长度正确）一直未被回收，`rx` 计数不再增长"的现象，需要继续在 `stm32n6_receive()` 的 `rxhead` 与尾指针推进逻辑上收敛。

**注意**：`stm32n6_ethprobe.c` 是调试探针，接口 up 之后不要再执行 `eye_cam eth probe`（会重配 ETH1 打断在线连接）。

## 四、构建与约束（务必遵守）

```bash
cd openvela
./build.sh vendor/openvela/boards/atk-dnn647/configs/eye --cmake -j$(nproc)
```

| 约束 | 值 | 说明 |
|---|---|---|
| 固件上限 | `nuttx.bin < 1,114,112 B` | FSBL 的 LRUN 窗口（`EXTMEM_LRUN_SOURCE_SIZE = 0x110000`） |
| RAM 上限 | `_ebss < 0x34200000` | AXISRAM3-6 是 NPU 张量池，越界即静默破坏推理 |
| 改 defconfig 后 | 必须 `rm -rf cmake_out/atk-dnn647_eye` | `.config` 不会自动从 defconfig 重新生成 |
| Flash 布局 | FSBL `0x70000000` / 应用 `0x70100000` / eye 权重 `0x70400000` / face 权重 `0x70700000` | **禁止整片擦除**，会丢权重 |
